# NUTNCSH(台南大學選課助手),是一個擁有多功能的輔助選課系統的chrome extension

目標功能

1. (增加篩選項目)可依照課程地圖上的課顯示這學期有開的相關課程:可以選擇不同入學學年度,和科系,和是否可選
   ex選修中的必修這學期的課
2. (增加篩選項目)可依照某天某節數來從**所有課**中找對應的課(目前你還是要你一個個點科系)
   ex我剛好要補星期二67節
3. 點選課程可以同時顯示課程大綱和decard對應老師評價,這樣就不用再切來切去
4. 有一張表可以看目前的畢業進度和各課種完成率(依照課程地圖,會依照你正在上的課來預估上完的結果)

改進UI和使用體驗
  1. 增加課程圖標,讓你可以更清楚的看到這課到底是屬於哪種課
  2. 改進課程時間標示,讓你可以更清楚看到這課到底是什麼時後的(就把數字圖標加個時間)
  3. 改進課程資訊的顯示,讓可以自由排列和隱藏某些資訊

額外功能(未來再想辦法實現)
  2. 快速選課模式,可以對著課表,會從必修顯示不會衝突到的課程(後出現不能充到之前的),你可以選,然後點下一步,然後是必選修然後是自由選修,最後產出你要選的課程
  1. 可以將喜歡的課程先選取起來存好再整理
  2. 自動搶課,將你存好的課在可以選的那一刻直接幫你選
